# ArithmeticTrainer

A Java command-line application that generates and administers arithmetic quizzes to help users practice basic math operations.

---

##  Features

- **Multiple Operations:** Supports addition, subtraction, multiplication, and division.
- **Customizable Quizzes:** Choose the number of questions and difficulty level.
- **Interactive CLI:** Prompts the user for answers and provides immediate feedback.
- **Scoring System:** Tracks correct and incorrect answers and displays the final score.
- **Randomized Questions:** Generates random operands within the selected difficulty range.

---

##  Requirements

- **Java SE 8** or higher.
- A terminal or command-line environment.

---

##  Installation & Usage

1. **Clone the repository:**
   ```sh
   git clone https://github.com/oktaykorkut/ArithmeticTrainer.git
   cd ArithmeticTrainer
   ```

2. **Compile the source file:**
   ```sh
   javac ArithmeticExerciseProgram.java
   ```

3. **Run the application:**
   ```sh
   java ArithmeticExerciseProgram
   ```

4. **Follow on-screen prompts** to select:
   - Quiz operation(s) (e.g., addition, multiplication).
   - Number of questions.
   - Difficulty level.
